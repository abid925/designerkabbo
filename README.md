# Kabbo — Jersey & Apparel Designer Portfolio

Portfolio website for **Kabbo Ahmed**, Senior Graphics Designer at **ForNA Printing**, specializing in custom jersey design, Adobe Photoshop 3D kit mockups, Adobe Illustrator vector artwork, and print-ready sublimation tech packs.

## Run Locally

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deploy to Netlify

`netlify.toml` and `public/_redirects` are pre-configured:
- **Build command:** `npm run build`
- **Publish directory:** `dist`
